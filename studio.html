MISSION / VISION / VALUES制作を支える理念と判断原則

VOID TO FORM 無から有へ。

CORE PHILOSOPHY 中心思想

創造の可能性を、社会の価値へ。

XEN CSJは、独創性と社会貢献の融合を理念の中心に据える。

自分自身の美学と新しい表現への挑戦を大切にし、創作によって人々や社会に価値を生み出す。

MISSION / VISION / VALUES — 正式文章

MISSION 存在意義

独創的な表現で、想いを社会に届く価値へ。

独自の感性と創造力を活かし、人々の想いや課題を形にする。

表現の領域を超えて、受け取る人にとって意味のある価値を生み出す。

VISION 目指す未来

創造が、人々の心と社会を豊かにする未来。

新しい発想や表現が、人々の感情や暮らしに前向きな変化をもたらし、創造の価値が社会に広がる未来を目指す。

VALUES 4つの行動指針

  1. 01

    CONTRIBUTION 貢献

    価値で、応える。

    相手の目的に向き合い、確かな成果と信頼を積み重ねる。

    受託制作では、顧客と合意した目的・品質・条件を優先し、長期的な信頼を大切にする。

  2. 02

    ORIGINALITY 独創性

    独自の答えを、創る。

    自分自身の美学と相手の目的を掛け合わせ、既存の正解にとらわれない価値を生み出す。

  3. 03

    EVOLUTION 進化

    可能性を、拓く。

    現状に満足せず、新しい技術・発想・表現を磨き続ける。

  4. 04

    PASSION 情熱

    創造を、絶やさない。

    ものづくりへの情熱を原動力に、持続可能な創作を続ける。

CREATIVE PROCESS創作を、次の可能性につなげる。

理念を制作活動につなぐ、4つのステップ。

  1. DISCOVER

    想いや課題を見つめ、
    表現の手がかりを探す。

  2. CREATE

    感性と技術を重ね、
    ひとつの形にする。

  3. SHARE

    作品を届け、
    人や社会とつながる。

  4. GROW

    反応から学び、
    次の創造へ進む。

PHILOSOPHY 表現の思想

VOID TO FORM — 無から有へ。
周波数は、形となり、物語となる。

扱うのは“情報”ではなく“周波数”。目に見えない感情、温度、余白、緊張感——それらを丁寧にかたちへ昇華させ、ブランドの核となる世界観を創り出します。

たったひとつの作品が、誰かの人生の景色を変えることがある。その信念のもと、「魅せる表現」を追求しています。

デザイン、映像、音、空間。すべてをひとつの世界観で統合し、“XENの周波数”として表現しています。
